MooPay is a TypeScript app that runs on Node 22. It has a chat server, a pay window, a claim page, and a small API for outside agents.

:::cards
- [Architecture](/docs/developers/overview/architecture) See the parts and how they connect.
- [Agent keys](/docs/developers/agent-api/agent-keys) Let your own bot pay with limits.
- [Payment flow](/docs/developers/inside-the-code/payment-flow) Follow one payment through the code.
- [Run it yourself](/docs/developers/overview/run-it-yourself) Start your own copy.
:::

## What you can build

| Goal | Use |
| :- | :- |
| Let a bot send money with a budget | The [agent API](/docs/developers/agent-api/agent-keys). |
| Run your own MooPay | [Run it yourself](/docs/developers/overview/run-it-yourself). |
| Add a new chat tool | See [Payment flow](/docs/developers/inside-the-code/payment-flow). |
| Connect from Claude or ChatGPT | Coming soon: [MCP connector](/docs/coming-soon/roadmap/mcp-connector). |
