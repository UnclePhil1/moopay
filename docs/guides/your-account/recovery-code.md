---
title: "Recovery code"
description: "Keep the code that brings your account back on a new browser."
---

Your recovery code is the only way to restore your account on a new browser or device.

## See it

Type `/recovery`. It shows once in a pop-up, never in the chat.

## Use it

On a new browser, type `/restore`, paste the code, and pick **My device**.

## Protect it

Type `/lock` to add a passphrase. Then the code on your device is locked.

## If you lose it

If you still have your signed-in browser, type `/reset` for a new code. If you have neither, MooPay cannot restore the account. The money in the agent wallet can still be recovered with the wallet key from `/export`, if you saved it.

:::warning
Never share your recovery code. MooPay staff will never ask for it.
:::
