---

## What is private

- The chat can run inside sealed enclaves on [NEAR AI Cloud](https://near.ai), so even the host cannot read it. This needs the server to be set up with that key. Type `/privacy` to see how your chat is handled.
- Chat history is optional. Type `/history` to choose. Old chat is deleted after 30 days by default.
- You need no email or sign-up.

## What is not private

- Payments on public chains are public. Anyone can look up an address on a block explorer.
- 1Click can add some privacy on swaps, but it does not hide the receiver on the final chain.
- Claims are not zero-knowledge.

## Delete your data

Type `/delete` to erase your data from MooPay. Chain records stay, because no one can remove them.
