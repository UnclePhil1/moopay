---
title: "Commands"
description: "Look up every slash command you can type in the chat."
---

Type `/` in the chat to see the list.

| Command | What it does |
| :- | :- |
| `/send` | Send to any wallet address. |
| `/claim` | Make a private claim. |
| `/account` | Show balance and deposit address. |
| `/status` | Show recent payments and claims. |
| `/add` | Add money from any chain. |
| `/withdraw` | Take your money out. |
| `/stake` | Stake into rNEAR. |
| `/rules` | Show your limits and payout wallet. |
| `/agents` | Manage keys for other AI agents. |
| `/privacy` | See who can read your chat. |
| `/history` | Choose whether chat is saved. |
| `/recovery` | Show your recovery code. |
| `/restore` | Get your account back on a new browser. |
| `/lock` | Protect the recovery code with a passphrase. |
| `/export` | Show your wallet key. |
| `/freeze` | Stop all spending now. |
| `/unfreeze` | Lift the freeze. Needs your recovery code. |
| `/signout` | Remove this browser's access. |
| `/reset` | New recovery code, signs out other browsers. |
| `/delete` | Erase your data from MooPay. |
| `/clear` | Clear this chat. |
| `/help` | See what the agent can do. |
