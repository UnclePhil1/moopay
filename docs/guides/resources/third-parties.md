title: "Third parties"
description: "See the outside services and tools MooPay depends on."
---

Click a name to visit its website.

| Service | What MooPay uses it for |
| :- | :- |
| [NEAR Intents](https://near-intents.org) | Swaps and cross-chain delivery through 1Click. |
| [NEAR](https://near.org) | The agent wallet, signing, and claims. |
| [NEAR AI](https://near.ai) | Private AI inside sealed enclaves. |
| [Rhea Finance](https://rhea.finance) | rNEAR liquid staking. |
| [Reown](https://reown.com) | Lets phones pick any wallet to pay from. |
| [NEAR Wallet Selector](https://github.com/near/wallet-selector) | Connects NEAR wallets in the pay window. |

If one of these has an outage, the related feature can fail. Funds in flight through 1Click follow its own refund rules.
